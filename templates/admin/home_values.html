Getting set up

  1. Add RENTCAST_API_KEY in Railway Variables, using the API key from your RentCast account.
  2. Come back here and run a test lookup with a real address.
  3. Add a test home as a homeowner. Its value page should say it came from RentCast.
  4. When you upgrade your plan, raise the three limits above.
